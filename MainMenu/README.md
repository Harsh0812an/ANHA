# Main Menu

The **Main Menu** serves as the central entry point of the ANHA Bioinformatics Toolkit. It provides a centralized terminal-based interface for accessing different bioinformatics modules developed under ANHA.

Users can navigate through available modules by selecting the corresponding menu options.

---

## Features

- Centralized navigation
- User-friendly menu-driven terminal interface
- Access to implemented bioinformatics modules
- Handles user input and module selection
- Modular structure supporting future expansion

---

## Current Modules

### Phase 1 – Completed
- DNA Analyzer
- Sequence Alignment
- Mutation Finder

### Phase 2 – Under Development
- Sequence Validator
- ORF Finder
- Protein Translator
- Biomedical Calculator

---

## Workflow
```text
Start Program
      │
      ▼
 Display Main Menu
      │
      ▼
Select Desired Module
      │
      ├── DNA Analyzer
      ├── Sequence Alignment
      ├── Mutation Finder
      ├── Sequence Validator
      ├── ORF Finder
      ├── Protein Translator
      └── Biomedical Calculator
      │
      ▼
Execute Selected Module
      │
      ▼
Return to Main Menu / Exit
```
